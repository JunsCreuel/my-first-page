웹 개발을 배우는 이유

제가 생각하는 플랫폼을 MVP까지 직접 만들어 창업하고 싶기 때문입니다.
중학생 때부터 AI 프로그래밍과 리눅스를 해 왔지만, 아이디어를 빠르게 웹으로 구현하려면 HTML, CSS, JavaScript 같은 웹 개발 기초가 필요하다고 느꼈습니다.

이번 과정에서 만들고 싶은 것

  • 현재 기획까지 끝마친 플랫폼 제작
  • 아이디어를 정리하고 검증할 수 있는 MVP 프로토타입
  • 창업을 준비하며 보여줄 수 있는 포트폴리오 사이트

배우고 싶은 기술

기술 배우려는 이유
HTML & CSS 웹 페이지 구조잡고 디자인하고 오류 해결하기
JavaScript 사용자와 상호작용하는 기능 구현하기
반응형 웹 모바일·PC 모두에서 잘 보이는 페이지 만들기
Git & GitHub 코드 관리와 협업하기

개발자로서 가져가고 싶은 태도

  • 아이디어만 내지 않고, 작은 것부터 직접 만들어 완성하기
  • 모르는 것을 두려워하지 않고 꾸준히 배우기
  • 기본기를 다지고 실제로 프로젝트를 진행하며 경험을 쌓기
